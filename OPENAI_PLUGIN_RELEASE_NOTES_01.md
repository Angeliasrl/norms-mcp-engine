# OpenAI plugin release notes 01

Initial public submission of NORMS: Evidence & Scope.

- One read-only MCP tool: `assess_normative_reliance`.
- Stateless server with no authentication and no application persistence.
- Canonical typed public input contract with strict validation.
- Deterministic, fail-closed outputs exposing blockers, unknowns and unexamined areas.
- No document parsing, law retrieval or inference of normative conditions from free text.
- Verified production MCP endpoint and public policy pages.
- Five positive and three negative reviewer tests included.

This initial submission does not add UI, skills, document upload, write actions or additional tools.
